# Data dictionary

Generated by `npm run data` into `public/data/europe.json` (`Dataset`, see `src/data/types.ts`).
Source columns are defined in `METRICS` in `scripts/lib/buildDataset.ts`.

## City fields

| Field               | Derivation                                                                                                                      | Visual channel                  |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `workingPeople`     | Economically active population 20-64; fallbacks: persons employed 20-64, active population male + female (all ages), total jobs | arc angle within the country    |
| `commuterRate`      | inbound commuters / workplace jobs. NACE A-T sum replaces a published total below 2/3 of that sum; above 1 is missing           | hatched part of the segment     |
| `maleShare`         | active population 20-64 male / total; fallback: all ages                                                                        | dotted radial tick              |
| `unemploymentRate`  | unemployment rate (%)                                                                                                           | -                               |
| `unemploymentLevel` | low < 7 <= medium < 12 <= high (`src/config/encoding.ts`)                                                                       | grey band, 1 / 2 / 3 steps      |
| `commuteMinutes`    | average time of journey to work (minutes)                                                                                       | radial offset from the baseline |
| `sectors`           | jobs in public (O-Q), trade (G-I), business (M, N), industry (B-E)                                                              | -                               |
| `biggestSector`     | sector with the most jobs                                                                                                       | fill colour                     |
| `missing`           | names of fields above that are null                                                                                             | missing-data styling            |

## Commute scale

Linear, shared by all donuts. `COMMUTE.domain = [20, 55]` minutes is clamped to 0-1 and maps
to `theme.donut.commuteSpan` of the radius. The guides at 30 / 40 / 50 min are drawn at the radius
a segment with that commute time would have. Missing commute: segment on the baseline with a
dashed inner edge.

## Coverage

The CSV is sparse: commute time exists for 27 cities, commuters for 25, unemployment rate for 39.
Lisboa and Porto: the published 2023 workplace-jobs total is about a third of the year before, while the
NACE columns stay on the earlier scale (trade alone is as large as the published total). Their commuter
rates use the NACE sum, about 54% and 52%.
The Polish cities only have total jobs and sector data.
`npm run data` prints the full coverage table.
